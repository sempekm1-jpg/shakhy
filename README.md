# Шахи вдвох

Шахи на двох телефонах у браузері, зокрема на iPhone. Нічого встановлювати не треба: один гравець створює гру й надсилає посилання іншому.

Ходи передаються через безплатний сервіс [ntfy.sh](https://ntfy.sh) під випадковим кодом гри. Кожен гравець може сам увімкнути підказки рушія, і суперник не бачить, чи вони ввімкнені. Обидва гравці бачать це правило на сторінці.

Сторінка відкривається за адресою https://sempekm1-jpg.github.io/shakhy/
